# 差异分析：对比写法、诊断与红线

## 设计矩阵与对比

- 两水平因子：`~ 组` 即组间比较；加协变量 `~ 组 + 协变量`。
- 配对设计：`~ 配对个体 + 组`（个体作 block）或等价 paired 参数；**把配对样本当独立**是最常见致命错误。
- 连续变量效应：先确认线性假设或分箱说明；不要把连续变量悄悄二分。
- 多组：全局 F 检验先行，再写感兴趣的两两对比（contrast），数量与多重比较说明一致。
- 对比方向写清（谁减谁），结果解读方向与 logFC 符号一致。

## 诊断清单

- [ ] 均值-方差关系图正常（无异常低表达基因群主导）
- [ ] p 值直方图近似均匀（左端富集=有信号；整体偏峰查模型）
- [ ] 显著基因数合理（数千以上需查批次/样本混入）
- [ ] 设计矩阵无秩亏/共线警告未处理
- [ ] 样本标签与分组无错位（热图/树状图核对）

## 常见红旗（审计他人结果时）

- 未报告过滤规则与软件版本 → 不可复现。
- 显著基因列表含大量线粒体/核糖体基因且未讨论 → 提示文库组成/批次问题。
- logFC 与 p 都"漂亮"但无诊断图 → 要求补诊断。
- 用"差异倍数前 100"代替统计筛选 → 说明阈值体系不一致。
- 未校正批次而批次与组相关 → 结果可能全是批次差异。

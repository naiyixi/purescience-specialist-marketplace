# 临床研究方案书撰写

## 目标

把设计决策变成一份**任何独立读者都能执行、审阅者能挑错、注册机构能核对**的方案文档：结构完整、要素一致、版本可追溯。

## 方案结构骨架（对照通用方案要素，按研究类型增删）

1. 封面与版本：题目（结构式：设计+人群+干预+对照+结局）、方案编号与版本、日期、作者。
2. 背景与依据：疾病负担与研究缺口（引文献，不铺陈）、前期证据摘要、本研究的科学问题与假设。
3. 目的与终点：主要目的/次要目的；主要终点（定义、测量方法、时点、分析集）、次要终点、探索性终点——**终点与目的的对应关系逐一写明**。
4. 设计：类型（平行/交叉/析因/整群；优效/非劣效/等效）、随机化与盲法、研究时程图（筛选/治疗/随访窗口）。
5. 受试者：纳入/排除标准（可操作、可核对）、筛选流程、退出/替换规则。
6. 干预：试验组与对照组的剂量/方案/合并用药限制、依从性评估、揭盲规则（如适用）。
7. 评估与访视：时间表（访视窗 ± 天数）、每次访视采集项、样本/生物样本处理与保存。
8. 安全性：不良事件定义与报告流程、严重不良事件上报时限、数据安全监查（DSMB 如需要）。
9. 统计：样本量计算（公式+参数出处）、分析集定义、主要/次要分析、缺失处理、多重性、亚组与敏感性——与 SAP 一致或指向 SAP。
10. 质量与伦理：伦理委员会、注册（试验注册号）、知情同意流程、隐私与数据保护、方案偏离与修正流程、发表政策。
11. 参考文献与附件。

## 撰写规则

- **一致性优先**：方案内部各章节数字/定义必须一致（终点定义在第 3 节与第 9 节相同；时间窗在时程图与访视表相同）；写完做一次全文交叉核对。
- **可操作性**：每条标准写成"能否判定"式（如"入组前 4 周内未使用 X 类药物"优于"无相关用药史"）。
- **出处纪律**：样本量参数（最小差异、SD、事件率）给出处或标"待定，来源：前期数据/文献 X"；不编。
- **版本管理**：每次修改生成新版本号与变更记录（谁/何时/改了什么/为何）。
- **语言**：中文方案用简体中文；统计与术语夹注英文（如 ITT、PP、DSMB）；不写营销式"有望突破"句。

## 审计清单（审他人方案时逐项）

- [ ] 题目/目的/终点/统计四者指向同一研究问题
- [ ] 主要终点有明确定义+时点+分析集，无"主要终点待定"
- [ ] 样本量公式与参数齐全且有出处
- [ ] 纳入排除可操作；筛选数与招募计划衔接
- [ ] 随机化/盲法/揭盲规则完整（如适用）
- [ ] 安全性报告流程合规（AE/SAE 定义与时限）
- [ ] 注册号与伦理状态有记录
- [ ] 各章节数字一致；版本与变更记录完整

## 红线

- 不替用户填写需要临床/统计/法规专家拍板的空缺（如最小临床意义差异）——列出待定项与建议获取途径。
- 不承诺监管结果（"可支持注册"式表述要限定为"可支持……的探讨"）。
- 不省略安全性章节（哪怕用户只要"初稿框架"也要留占位与提示）。
- 方案不是已执行的研究：不得把方案写作冒充执行证据。

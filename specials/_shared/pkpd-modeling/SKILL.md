# 药代/药效建模（PK/PD）

## 目标

把浓度-时间与效应数据变成**模型可辩护、参数可解释、单位可审计**的 PK/PD 结果：数据要求先讲清、NCA 与模型化选对路、群体模型结构完整、验证诚实、剂量结论不越数据。

## 核心工作流

1. **数据要求盘点**（缺项先澄清）：给药方案（剂量/时间/途径）、采样时间（密集 vs 稀疏）、浓度单位与分析方法（LLOQ 以下如何处理）、个体协变量（体重/年龄/肾功能等）、效应数据（如适用，含基线）。
2. **NCA vs 模型化**：
   - NCA：参数少、假设少，适合密集采样的描述性总结（AUC/Cmax/Tmax/t½/CL/F/Vd 等，按给药途径给相应参数）。
   - 模型化：稀疏数据、群体变异、协变量、暴露-反应、模拟——需要结构模型+误差模型。
3. **群体 PK/PD 建模**：
   - 结构模型：房室数选择依据（诊断图/信息准则，不唯 AIC 论）。
   - 随机效应：个体间变异（BSV）与残差模型选择（加性/比例/混合）；收缩（shrinkage）报告。
   - 协变量：预设候选（生理合理性）→ 逐步或全模型法 → 效应量与临床意义并报；**不做纯数据驱动的协变量淘金**。
4. **暴露-反应与剂量**：暴露指标（AUC/Cmax/Ctrough）与效应/安全性关联建模；剂量选择的依据是目标暴露区间而非单点；给出剂量-暴露-效应链的不确定度。
5. **验证**：拟合诊断（GOF/条件加权残差/个体拟合）；Bootstrap/模拟校验（如适用）；外部数据验证有就做、没有明说。
6. **转化缩放（如适用）**：种属间异速缩放/体外体内外推的前提与不确定性说明；只做用户明确要求且有数据支撑的范围。

## 红线

- 单位/量纲错误零容忍：浓度（ng/mL vs µg/mL vs nmol/L）、剂量（mg/kg vs mg）、时间单位全程一致，换算写系数。
- 不输出个体化给药方案（那是处方决策）。
- LLOQ 以下数据不静默删除或随意赋值：处理方法（如 M1/M3 类或似然法）写明。
- 不把模型参数当"真实生理值"过度解读（模型是简化）。
- 协变量效应报告效应量与 CI，不只报 p。
- 不编造浓度数据、剂量历史、模型拟合优度。

## 交接语义

- 不确定度/单位审计 → uncertainty-units-audit；统计表述 → statistical-inference。
- 数据来自临床试验/文献 → 用户提供；需检索 → literature/pubmed 连接器。

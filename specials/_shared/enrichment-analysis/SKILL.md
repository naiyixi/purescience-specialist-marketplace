# 功能富集分析

## 目标

把基因列表/排序变成**可辩护的通路级结论**：方法匹配输入形态、背景正确、多重比较受控、结果去冗余、解读不越界。

## 方法选择

| 输入 | 方法 | 要点 |
|---|---|---|
| 显著基因列表（阈值化） | ORA（过表达分析） | 背景集必须正确（检出的全部基因，不是全基因组）；列表阈值影响结果 |
| 全基因排序（如按统计量/效应） | GSEA 类排序富集 | 不丢阈值下信息；方向性（上调/下调）分开或带符号 |
| 单样本/小批量 | 单样本富集（ssGSEA 类） | 样本级打分，跨样本比较用；注意打分分布解释 |
| 多组学/自定义 | 相应专用方法 | 超出默认范围时明说 |

## 基因集库

- 常用公开库：GO（生物过程/分子功能/细胞组分）、通路库（KEGG 等，注意许可与版本）、分子特征库（MSigDB 类 hallmark/标志集）。以官方版本号记录；KEGG 等商用许可需用户确认使用场景合规。
- 物种/标识符：基因 ID 与基因集库 ID 体系一致（或做映射并记录版本与映射率）；映射率低要警告。
- 不编造通路定义：所有基因集来自声明的库文件。

## 执行要点

- ORA：背景 = 该平台检出的基因全集（写明数量）；显著列表阈值与差异分析一致。
- GSEA 类：输入排序指标（如 logFC 或统计量）写明；置换次数/种子记录；富集分数方向解释。
- 多重比较：对"测试的全部通路数"校正（FDR）；报告显著通路数与总测试数。
- 冗余处理：相似通路大量同现是正常的（共享基因）——聚类/代表通路呈现，不把 50 个重叠通路当 50 个独立发现。

## 解读红线

- 富集 ≠ 因果：通路富集只是统计模式，不能推出"该通路是机制/药靶"。
- 不把 GO 术语当"通路"夸大（GO 是功能注释层级）。
- 结果受背景/列表阈值影响大时做敏感性说明。
- 不报告未经校正的原始 p 列表作为显著富集。

## 输出

方法（输入形态/库与版本/背景/置换与种子）+ 显著富集表（通路/基因数/重叠基因/p/FDR）+ 去冗余代表集 + 解读（方向与局限）。

# 富集分析常见陷阱与呈现规范

## ORA 陷阱

1. **背景集错误**：用全基因组当背景（实际检出的基因少得多）→ 假富集。正确背景 = 该次检测/过滤后的基因全集。
2. 输入"显著基因"的阈值漂移：logFC 与 FDR 阈值组合变化会大幅改变 ORA 结果——阈值体系与差异分析报告一致。
3. 双向基因混在一起跑 ORA：方向信息丢失；至少分开上调/下调或说明为何合并。

## GSEA 类陷阱

1. 排序指标选择：用 p 值排序（而非效应量/统计量）会把"最显著但效应极小"的基因排前；推荐效应量/检验统计量排序并说明。
2. 置换次数过低/种子未记录 → 结果不可复现。
3. 把"富集分数正"当"通路上调"：需结合基因方向解释；显式报告方向约定。

## 冗余与呈现

- 同现通路共享基因（如多个免疫相关 GO 项）→ 报告代表通路/聚类，附完整表在补充。
- 通路名自明化：不把缩写（如 "regulation of ..."）当读者都懂；给全称或注释。
- 图（气泡/网络/条形）遵循 scientific-visualization：坐标含义、色标、大小映射写清。

## 解读纪律

- 富集结果的三层语言：
  1. 事实层："X 通路在显著基因中富集（FDR=0.01，重叠基因 N 个）"——可直接写。
  2. 模式层："与免疫应答相关的基因集整体富集"——可写但要给基因集构成。
  3. 机制层："提示免疫通路参与发病"——必须回到原始文献/功能实验证据，否则标"待验证假设"。
- 禁止：把富集直接写成"该通路是发病机制/药物靶点"。

## 报告要素

方法（输入/库与版本/背景/算法与种子/阈值）+ 结果表（每通路：ID/描述/重叠或富集分数/基因数/p/FDR）+ 敏感性（换库/换阈值是否稳健）+ 局限。

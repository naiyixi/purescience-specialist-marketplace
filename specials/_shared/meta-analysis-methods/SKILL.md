# Meta 分析方法

## 目标

只在**合并有意义的条件下**做定量综合，并让每个方法选择（效应量/模型/异质性处理）可辩护；其余情况诚实降级为叙述性综合。

## 合并前的三道闸

1. **问题闸**：效应量定义一致（同一结局、同一测量时点、同一比较）。
2. **临床闸**：人群/干预/对照足够接近——差异大时先做亚组预规划而不是硬合并。
3. **方法学闸**：纳入研究是否提供可提取的效应量与方差；缺失关键数据的处理规则预设。

任一闸不过 → 不做 Meta，输出叙述性综合 + 说明为何不合并。

## 效应量选择

- 二分类：RR（队列/试验常用）或 OR（病例对照、调整后）；事件罕见时 OR/固定效应小心（连续性校正说明）。
- 连续：MD（同量表）或 SMD（跨量表；解释需回到原始量表）。
- 时间-事件：HR（需从原文或统计量换算，注明换算方法与近似）。
- 单臂率/诊断准确性：相应专用方法，不套两臂通用式。

## 异质性与模型

- 先看森林图与临床差异，再定量：Cochran Q（p 值）、I²（描述性，受研究数与精度影响）、Tau²（真实方差）。
- 固定效应模型：假设共同效应；随机效应模型：承认研究间方差（常用 DerSimonian-Laird，现代可用 REML，注明软件与版本）。
- 随机效应不"解决"异质性——它只是把异质性计入权重；异质性大到结论不可信时应拆亚组或降级叙述。
- 亚组/Meta 回归：预规划、交互检验（组间差异检验）而非"每组内显著与否"；避免事后数据驱动的亚组。

## 发表偏倚与稳健性

- 漏斗图不对称检验（Egger 回归等）需要 ≥10 项研究才较可靠；研究少时明确"无法可靠评估"。
- 若怀疑缺失研究：给出 trim-and-fill 或选模法结果时要同时给未校正结果与假设说明，不把校正后当主结果。
- 敏感性：排除高风险研究/更改模型/更改效应量/留一法，逐一报告对结论的影响。

## 输出与报告

- 每项研究一行：效应量与 CI、权重、偏倚风险。
- 合并结果：效应量 + 95% CI + I²/Tau² + 模型说明；语言与 evidence-grading 对齐（随机效应合并不是"更确定"）。
- 报告要素对齐 PRISMA（检索、筛选流程、纳入特征、偏倚、合并方法、异质性、发表偏倚、敏感性）——由 methods-writing-audit 校正文。

## 红线

- 不合并临床异质性过大的研究然后声称一个总体效应。
- 不把"统计显著合并"当"临床重要"；区间包含无效应且跨最小有意义差异 → 结论为"证据不足"。
- 不手工编造缺失的 SD/事件数：可依标准方法从 CI/p 换算，但必须写明换算公式与来源。
- 单研究 Meta 或研究数过少 → 明确标注并降格表述。

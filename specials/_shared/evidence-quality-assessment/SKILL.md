# 单篇证据质量评价（偏倚风险）

## 目标

用领域公认的工具对每篇纳入研究做**逐域、可辩护**的偏倚风险判定，产出能直接进入证据体分级（GRADE 起点）的研究级风险结论。

## 工具选择

| 研究类型 | 工具（现行版本） | 结构 |
|---|---|---|
| 随机对照试验 | RoB 2 | 5 域 + 总体 |
| 非随机干预研究 | ROBINS-I | 7 域（干预前/中/后）+ 总体 |
| 诊断准确性 | QUADAS-2 | 4 域 + 适用性 |
| 随机试验的聚类版 | RoB 2 聚类版 | 同 RoB 2 思路 |
| 病因/预后观察性 | 按设计选（队列/病例对照工具或 ROBINS-I 思想），避免只给"NOS 星级"当结论 | 视工具 |

说明：以各工具现行官方手册为最终依据；本技能给判定逻辑，不替代手册原文。星级评分工具（如 NOS）可作记录，但**不得替代域级偏倚风险判定**作为 GRADE 依据。

## 判定流程

1. 读全文（不只摘要）：方法段优先；摘要不足以判定偏倚。
2. 逐域判定：`低风险 / 有一定风险 / 高风险 / 信息不足`（工具用语按现行手册），每条判定给依据（引用原文做法，如"未报告分配隐藏，邮件联系无果→有一定风险"）。
3. 域级 → 研究级汇总：按工具规则合成（如 RoB 2 任一域高风险常致总体高风险；"有一定风险"多数域时的规则照工具手册）；不确定标"信息不足"并说明补全途径。
4. 输出每篇评价表：研究 ID | 各域判定 | 依据 | 总体 | 对 GRADE 的起点含义（无风险=不因偏倚降级；风险→evidence-grading 降级建议）。

## 红线

- 不凭摘要/预感打分；没有读到的细节标"信息不足"，不猜。
- 不编造"作者报告了 X"——所有依据必须能在原文定位。
- 不用总分替代域级判定；不把工具当清单打勾而不给理由。
- 评价人与筛选人建议分离（系统评价惯例：双人独立+分歧仲裁；单人时明说局限）。
- 高风险研究不自动剔除——记录并进入敏感性分析/GRADE 降级，而不是静默丢弃。

## 交接语义

- 研究级风险结果 → evidence-grading（作为降级域输入）。
- 若评价中发现的数字/统计问题（如错误分析单元）→ 转 statistical-inference 复核。

# 中文期刊投稿准备

## 目标

把中文研究稿件做到"投稿即过形式审查"：格式、参考文献、伦理表述、统计描述四件事一次做对，把退稿风险留在内容层面而不是格式层面。

## 工作流

1. **先取当期稿约**：目标期刊的稿约以期刊官网当期版本为准，逐条抄成检查表；稿约更新后旧模板一律作废。
2. **结构对齐**：题目、摘要（目的/方法/结果/结论）、关键词、正文层级、图表编号与标题位置，按稿约顺序摆放。
3. **参考文献按 GB/T 7714 著录**：中文文献保留原题名与原作者，英文文献按期刊要求的缩写与大小写；每条核对卷期页与 DOI，缺项不补齐、不猜。
4. **伦理与知情同意**：写明伦理委员会名称、批件号、知情同意形式（书面/口头/豁免）与豁免依据；回顾性研究写清数据来源与豁免审批。
5. **基金标注**：基金名称与编号按批准书原文，不缩写、不并列未参与本研究的项目。
6. **统计学描述**：样本量依据、检验方法与前提检验、效应量与置信区间、缺失数据处理、软件与版本，逐项可复现。

## 常见退稿点（逐条自查）

- 摘要与正文数据不一致（例数、均值、P 值）。
- 参考文献中文文献缺卷期页，英文文献作者超过三位未按稿约缩写。
- 伦理批件号缺失或与伦理委员会名称不匹配。
- 结论超出数据（观察性研究写"证实"）。
- 图表重复正文信息、图注无法独立读懂。

## 边界

- 不代替作者判断研究价值与创新性。
- 不编造基金编号、伦理批件号、投稿系统回执。
- 稿约冲突时以期刊当期原文为准，并明确标注所依据的版本日期。

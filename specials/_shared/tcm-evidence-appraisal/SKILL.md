# 中医药证据评价

## 目标

把中医药证据放到与其他干预同一把尺子上量：哪些结论有随机对照支持、哪些只是经验与机制推断，并把"证候"这一层的不确定性说清楚。

## 五个必查维度

1. **随机与分配隐藏**：随机方法是否可复现（随机数字表/中央随机），分配隐藏是否做到；"按就诊顺序分组"不算随机。
2. **盲法与安慰剂可行性**：汤剂/针灸的盲法如何实现（模拟剂、假穴），受试者与研究者的盲法分别评估；无法盲法时说明其对结局的影响方向。
3. **复方一致性**：方剂组成、剂量、煎法、批号与质控指标（指纹图谱/指标成分含量）是否报告；批次不一致时疗效无法归因。
4. **证候可重复性**：证候诊断标准来源（行业标准/指南/自拟）、两名医师一致性（Kappa）、纳入是否要求证候——自拟标准会限制外推。
5. **结局与差异**：主要结局是否临床相关（而非仅症状积分），是否报告最小临床重要差异；统计显著与临床意义分开写。

## 表述校准

- 有高质量随机对照 + 效应量明确 → "在……人群中，与……相比，……改善了……（效应量，95%CI）"。
- 仅有小样本或方法学缺陷研究 → "初步研究提示……，受样本量与盲法限制，尚不能据此改变实践"。
- 仅有名医经验、经典文献、机制研究 → "传统用于……，现代证据尚不足以评价其有效性"，不写成疗效结论。

## 边界

- 不给个体处方、剂量、煎服法与疗程建议。
- 不判断中西药相互作用与配伍禁忌（以说明书与临床药师为准）。
- 不把网络药理、分子对接等计算机预测写成疗效证据。

# 签名验证纪律（切分/泄漏/验证细则）

## 数据切分圣经

- 切分单元 = 独立观察单位（患者/个体/生物学重复），**不是**技术重复/孔/批次内样本。
- 同一患者多时间点样本必须同属一个切分桶（防样本级泄漏）。
- 时间前瞻性问题按时间切分（用过去训、未来验）。
- 外部验证集：独立采集、不同时间/中心/平台为佳；同源随机分出的"验证"只能叫内部验证。

## 泄漏自检清单（最常见翻车点）

- [ ] 特征选择/过滤是否只用了训练集？
- [ ] 缺失值插补是否在训练集内拟合后应用到验证集？
- [ ] 批次校正是否用全数据拟合后再切分？（是→泄漏；应训练内拟合）
- [ ] 阈值（如风险高低分组切点）是否由训练集确定？
- [ ] 有没有任何一步"看了全部数据再决定"？
- [ ] 重复样本是否跨切分？

任一"是"：该验证无效，需重做；不得以"影响不大"带过。

## 性能指标报告

- 分类：AUC（含 CI）、敏感度/特异度（注明阈值来源）、校准（校准曲线/截距斜率）。
- 生存：C-index（含 CI）、时间依赖 AUC、校准。
- 连续：相关/误差指标。
- 与基准比较：随机预测/临床基线模型（年龄性别等）对比，报告增量价值。
- 每次验证报告样本量与事件数；事件数过少（如 <10/特征）结果不可靠。

## 调参与报告

- 内层 CV 调参 → 外层 CV 估性能（嵌套）或独立验证集；报告两层结构。
- 随机种子固定并记录；重复（如 100 次）给性能分布。
- 最终模型固定后，任何"再看一眼"都进验证集污染——严格冻结。

## 模块类分析（WGCNA 等）附加纪律

- 软阈值、模块划分在训练集；模块-性状相关报告校正与置换 p。
- 模块成员基因表给全（含 kME 类指标）。
- "模块与表型相关"→ 描述性发现；验证模块生物学意义需独立数据/实验。

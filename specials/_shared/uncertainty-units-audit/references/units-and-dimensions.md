# 单位与量纲速查

## 量纲分析要点

- 任何物理/化学/临床公式：等式两边量纲必须一致；代入数值时单位先统一。
- 常见临床量纲：浓度（质量/体积）、摩尔浓度（mol/体积）、速率（质量或体积/时间）、清除率（体积/时间）、暴露量（浓度×时间，如 AUC）。
- 摩尔换算：质量浓度 → 摩尔浓度 = 质量浓度 ÷ 摩尔质量（注意分子量单位 g/mol 与浓度单位 g/L ↔ mol/L 的对应；mg/dL 需先统一为 g/L 再除，或直接用换算系数）。
- 比例/百分比：区分质量分数（w/w）、体积分数（v/v）、质量体积百分数（w/v，如 "5% 葡萄糖"= 5 g/100 mL）；"%" 无量纲，但含义必须注明。
- 国际单位（IU/U）与质量之间无通用换算：视具体物质（如维生素、酶、肝素）各有定义，缺换算表时必须询问或保持不可换算。

## 常用换算系数（写全口径）

| 被换算 | 系数 | 方向与依据 |
|---|---|---|
| 葡萄糖 | ×0.0555 | mg/dL → mmol/L（÷180.156 g/mol 的摩尔换算，反查 ×18.02） |
| 肌酐 | ×88.4 | mg/dL → µmol/L（反查 ÷88.4；×0.0113 为 µmol/L→mg/dL） |
| 尿素氮 BUN | ×0.357 | mg/dL → 尿素 mmol/L（按尿素含氮换算） |
| 白蛋白/总蛋白 | ×10 | g/dL → g/L |
| 钙 | ×0.2495 | mg/dL → mmol/L |
| 胆红素 | ×17.1 | mg/dL → µmol/L |
| 温度 | K = ℃ + 273.15；°F = ℃×9/5 + 32 | 物理定义 |
| 压力 | 1 kPa = 7.5006 mmHg | 物理定义（mmHg 与 torr 近似相等） |
| 能量 | 1 kcal ≈ 4.184 kJ | 物理定义 |
| 长度/体积 | 1 L = 1 dm³；1 mL = 1 cm³ | 物理定义 |

> 表格系数为通行医学换算；使用前仍建议反查一次来源（如检验报告单的参考范围单位、教科书换算表），因个别检验项的口径（游离/总、离子钙 vs 总钙）不同。

## 换算审计步骤

1. 目标单位是否明确（含子单位前缀：µ/m/n/k 各差 1000）。
2. 系数来源：是摩尔质量推导还是经验常数？推导的写出分子量。
3. 方向验证：用小样例手算（如 90 mg/dL 葡萄糖 ≈ 5.0 mmol/L）确认系数方向没错。
4. 反查一致性：用换算后的值代入原公式应能还原。

## 量级合理性核查

- 生理量级参照（仅作 sanity check，不作为诊断依据）：
  - 血钠 ~135–145 mmol/L；血钾 ~3.5–5.0 mmol/L；血糖空腹 ~3.9–6.1 mmol/L（~70–110 mg/dL）。
  - 肌酐 ~44–97 µmol/L（女）/57–111 µmol/L（男）量级。
  - 药物血浆浓度常在 ng/mL–µg/mL 量级；AUC 常用 ng·h/mL 或 µg·h/mL。
- 结果偏离生理/文献量级 ≥1 个数量级：停下来检查单位或系数，而不是直接报告。

## 书写规范

- 数值与单位间留空格（"5.0 mmol/L"）；单位用标准符号；避免歧义缩写（IU 注明物质）。
- 小数位由测量不确定度决定，见 propagating-uncertainty 参考。

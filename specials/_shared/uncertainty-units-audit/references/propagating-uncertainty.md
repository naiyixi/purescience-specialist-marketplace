# 测量不确定度传播与报告（工程化表述）

> 对应"测量不确定度表示指南"（GUM）的思想做中文工程化落地：分类 → 合成 → 报告。不追求形式化完全等价，但语义必须一致、可审计。

## 一、先定性：± 值到底是什么

合成前必须把每个 ± 归类：

| 语义 | 符号约定 | 说明 |
|---|---|---|
| 标准不确定度 | u | 等效标准差 |
| A 类评定 | u_A | 由重复观测统计（n 次，SD/√n 为均值标准误场景需区分是单次还是均值） |
| B 类评定 | u_B | 由经验/说明书/分布假设评定，如均匀分布 u = a/√3、三角分布 u = a/√6（a 为半宽） |
| 扩展不确定度 | U = k·u_c | 必须写包含因子 k（k=2 ≈ 95% 正态近似） |
| 极差/峰峰值/仪器分度 | 非标准不确定度 | 须折算或拒绝使用 |
| 置信区间 | CI | 属统计推断语言，有分布与置信水平，不与 GUM 分量混算 |

**语义未定义 ⇒ 禁止合成**：输出"± 语义未定义"，列出要补齐的信息，停在该步。

## 二、合成规则（一阶近似）

设结果 f = f(x₁,…,xₙ)，各输入不相关：

- 一般式：u_c² = Σ (∂f/∂xᵢ)² · uᵢ²
- 线性：f = aX + bY → u_c = √(a²uₓ² + b²u_y²)
- 乘除（相对不确定度不大时）：(u_f/f)² ≈ (uₓ/X)² + (u_y/Y)²
- 幂：f = X^n → u_f/f ≈ |n|·uₓ/X
- 相关输入：补协方差项 2·(∂f/∂x)(∂f/∂y)·cov(x,y)；不知相关性时明说"按不相关处理"并评估影响。

步骤：列出每个输入的标准不确定度 → 写出敏感系数 ∂f/∂xᵢ → 合成 u_c → 按需扩展 U = k·u_c。

## 三、报告格式

- `结果 = 估计值 ± 扩展不确定度（k=2，约 95% 置信，正态假设）`
- 或：`结果 = 估计值，标准不确定度 u = …`
- 不确定度与结果末位对齐；不确定度保留 1-2 位有效数字（如 12.34 ± 0.5 写 12.3 ± 0.5；0.5678 ± 0.003 写 0.568 ± 0.003）。
- 报告必须包含：不确定度分量表（来源/类型/值/分布假设）、合成公式、自由度若用于 t 扩展则说明。

## 四、医疗/科研场景高频陷阱

1. 把试剂盒 CV%（变异系数）当标准不确定度直接当 u 用：CV% 换算 u = CV% × 均值 / 100，并确认 CV 是批内/批间/总误差（总误差含偏倚，需拆解）。
2. 把仪器分辨率（如 0.1 mg 天平）当 u：分辨率通常按均匀分布折半宽处理。
3. 校准品/参考物质不确定度被忽略：溯源链上的定值不确定度应计入。
4. 平均值的 SE 与单次测量的 SD 混用：报告均值时用 SE=SD/√n（或说清对象）。
5. 把模型预测区间当测量不确定度：那是统计推断范畴，交给统计推断技能。
6. 把不同来源的扩展不确定度（k=1 与 k=2）直接 RSS。
